# 새로 배운 내용

## 주제 1: OOP 

**개념:** OOP의 고유 명사는 **현실 세계의 객체 개념을 기반으로 데이터를 속성(필드)과 기능(메서드)로 묶어 프로그램을 설계하는 패러다임**입니다.

* **객체:** 역할과 책임을 가진 주체 (누가 책임 질래? → A객체가 책임짐)
* **OOP:** 역할과 책임을 가지고 있는 주체의 협력으로 바꾸는 것

⚠️ **객체에 대해 오해하는 포인트:** 객체는 데이터를 담은 상자(X)  
* **ex)** 커피 ← 아이스 아메리카노 인 경우 다른 점이 ‘온도’ 밖에 없음. 좋은 설계가 아님.

```java
// 안 좋은 설계 예시
public class Coffee {
    protected String temperature = "HOT";
}

public class IceAmericano extends Coffee {
    public IceAmericano() {
        this.temperature = "ICE"; 
    }
}
