## 오늘의 생긴 질문과 답변 

Q)upstream과 origin의 차이가 뭐지?
>origin : 내 원격 저장소(fork한 내 GitHub)
>upstream : 원본 저장소(팀/Organization 저장소)


Q)clone과 fork의 차이가 뭐지?
>clone : 저장소를 내 컴퓨터로 복사
>fork : 남의 GitHub 저장소를 내 GitHub 계정으로 복사

Q)organization이 뭐지?
>여러 사람이 함께 사용하는 GitHub 팀/그룹 계정

Q)untracked와 tracked는 어떤 차이가 있지?
>tracked : Git이 변경사항을 추적 중인 파일
>untracked : Git이 아직 관리하지 않는 새 파일



## 한줄정리 

>클래스 : 현실을 반영해 속성, 기능,생성자를  하나로 정의한 설계도.
>메서드 : 클래스에서 기능을 구현한것. 
>생성자 :새롭게 객체가 만들어질 때마다 값을 새로 초기화 해주는 특별한 메서드.
>객체 : 클래스가 실체화 된것.
>상속: 자식이 부모에게 속성과 기능을 복사해 달라고 요청하는 것.
